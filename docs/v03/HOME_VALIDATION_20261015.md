# 홈 조회 P0 · 2026-10-15 (KST)

## 기준 및 구현

`codex/v03-influencer-mvp`의 `b1b7c68e20fcc1ced9ed9fe5829beca46fa18273`에서 시작했다. docs/v03의 제품·검토 계약을 따른다.

- 현재 V03 사용자 ID와 기존 Supabase RLS로 협찬/콘텐츠/Task/일정 Review를 조회한다. 첫 100개만 잘라 보여주지 않고 ID cursor로 다음 페이지를 읽는다. 성과·광고 코드·원본 텍스트·이미지는 조회 projection에서 제외했다.
- 진행 중, 보류, 완료 목록을 분리했다. 협찬 이름·저장된 상태·가편/업로드 날짜와 상세/원본 가이드 진입을 제공한다. 협찬 카드와 Task를 누르면 기존 상세 URL로 이동한다.
- 다음 할 일은 진행 중 협찬의 미완료 Task 전체다. 지난 기한부터 날짜 오름차순, 이후 날짜 없는 항목 순으로 표시한다. 임의의 마감일이나 시각을 만들지 않는다.
- 보류/완료 협찬에 남은 미완료 Task도 해당 협찬 아래에 모두 표시한다. 상태만으로 Task 완료를 가정하거나 기한 지난 항목을 숨기지 않는다.
- 가편/업로드 날짜는 기존 Task가 기준이다. Task가 없으면 Review의 원문 미기재와 불명확/판독 불가를 구분한다. 근거가 없으면 확인 정보 없음으로 표시한다.
- 브라우저의 달력 날짜로 오늘/기한 지남/예정을 표시한다. UTC 변환이나 임의 자정 시각으로 due date를 해석하지 않는다. 날짜 표시는 분 단위 및 포커스 복귀 시 갱신하며 협찬 상태는 변경하지 않는다.
- 로그인 전, 로딩, 빈 목록, 진행 중만 없는 상태, 연결 오류/재시도, 15초 제한, 로그아웃 후 데이터 제거를 처리한다. 취소·시간 초과·이전 세션의 늦은 응답은 화면을 복원하지 않는다.
- 모바일 목록 바로가기는 페이지 URL을 바꾸지 않고 진행 중/할 일 구역으로 스크롤·포커스한다. 브리프 가져오기 진입은 모든 홈 상태에서 제공한다.

- 완료/보류에 남은 미완료 Task도 각 목록에서 보임을 확인. 협찬 상태는 그대로 유지했다.

## 한계 및 범위
