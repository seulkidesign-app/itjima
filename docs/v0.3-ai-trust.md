# V0.3 · AI Trust Floor

## Goal

Do not make Itjima broadly smarter yet. Raise the minimum trust level required for real-use testing.

### Product contract

1. If the time is clear, interpret it correctly.
2. If the input is ambiguous, ask instead of guessing.
3. If the date/time is invalid, never silently normalize it into another schedule.

## Batch 1

- Korean contextual dayparts: `저녁 7시`, `밤 10시`, `새벽 2시`
- Compound relative offsets: `한 시간 반 뒤`, `2시간 30분 후`
- Invalid date/time guard: `2월 30일`, `25시`, `75분`, invalid 24h clocks
- Broad dayparts without a clock: `내일 저녁에 치과` must not silently become an exact hour

## Out of scope for this batch

- Multi-event creation
- Recurrence
- Location/weather context
- Automatic rediscovery
- Large LLM evaluation infrastructure
- New UX/navigation features

## Exit rule

This branch may only move forward when release tests and Preview build are green. Real-use failures collected during V02 QA become the next regression cases.
