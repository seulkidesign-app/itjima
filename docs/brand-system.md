# itjima Brand System

## Locked brand marks

- Wordmark: `itjima` (always lowercase in logo contexts)
- Wordmark typeface: Playpen Sans Medium, weight 500
- Wordmark ink: `#2E2E2E`
- Landing logo dot: `#FFE658`
- Launcher / favicon master: approved `ij` symbol on `#FFF986`
- Launcher symbol ink: `#2E2E2E`
- Canonical wordmark source: Figma landing node `455:33`

Do not replace the logo wordmark with Pretendard, uppercase `ITJIMA`, or Korean `잊지마`. Korean `잊지마` remains the product/service name in body copy, SEO, install labels, and Korean UX writing.

## Brand vs product UI

### Brand layer
Use for landing, app chrome logo, login/auth brand moments, launcher icon, favicon, OG/social preview, and marketing.

- Playpen Sans Medium 500
- Lowercase `itjima`
- Warm yellow / ivory surfaces
- Organic `ij` symbol

### Product UI layer
Use for functional screens and controls.

- Pretendard / system fallback
- Neutral ink and surfaces
- Yellow as action/schedule emphasis
- Lucide icons
- 4pt spacing grid

Do not use the logo dot as a generic section bullet or screen-title decoration.

## Product chrome baseline

- Mobile horizontal gutter: 20px
- Mobile header: 56px
- Minimum touch target: 44px
- App logo height: 24px
- Primary glyphs: 18–20px
